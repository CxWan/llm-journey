# llm-journey

我的 AI 应用开发学习仓库，配合 30 天冲刺计划使用。

## 内容规划

- `hello_api.py` — 第一次调用大模型 API（glm-4-flash）
- `main.py` — FastAPI 服务，含 `POST /summarize` 文本摘要接口
- `notes/` — 每日踩坑记录与面试向笔记

## 环境

- Python 3.14 + uv（包管理）
- pip 源：清华镜像
- Git + SSH 接入 GitHub
